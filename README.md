# Forwarded to Uncle Jim

An out-of-office reply for Thanksgiving that hands every urgent request to Uncle Jim, then warns you exactly how the handoff will go: a 40-minute story about his 2014 knee surgery.

> I’m OOO for Thanksgiving; I’ve forwarded all urgent requests to my Uncle Jim, who will likely respond with a 40-minute story about his 2014 knee surgery.
